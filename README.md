# Restauracja Smaku

Projekt strony restauracji przygotowany w React i Vite.

## Uruchomienie

```powershell
npm install
npm run dev
```

Po uruchomieniu aplikacja jest dostepna lokalnie pod adresem pokazanym w terminalu, domyslnie:

```text
http://127.0.0.1:5173/
```

## Przydatne komendy

```powershell
npm run build
npm run lint
```
